Esta página es sobre el sitio web. Cada app tiene su propia política de privacidad: Pomoluna.

Este sitio web

Este sitio web no tiene cookies ni publicidad, y no carga nada de otros sitios. El sitio no guarda nada en tu navegador.

Conteo de visitas

Para saber cuánta gente lo visita, el sitio cuenta las visitas con GoatCounter, un contador de visitas de código abierto a cargo de Martin Tournoij (Irlanda), en servidores de Hetzner en Finlandia y Alemania. Registra la página, el sitio desde el que llegaste, y tu navegador, sistema operativo, idioma, ancho de pantalla y país. Tu dirección IP solo se usa para saber el país y para no contar dos veces la misma visita: se guarda en memoria como máximo ocho horas y nunca se almacena. No hay cookies ni perfiles. Los conteos se guardan 1000 días. Contamos las visitas para entender cómo se usa el sitio, que es nuestro interés legítimo (art. 6.1.f del RGPD). Mirá la política de privacidad de GoatCounter.

Alojamiento

El sitio está alojado en GitHub Pages (GitHub, Inc.). Como cualquier servidor web, GitHub guarda registros técnicos que pueden incluir tu dirección IP. Mirá la declaración de privacidad de GitHub.
