This website

This website has no cookies, no ads, and loads nothing from other websites. The site stores nothing in your browser.

Counting visits

To know how many people visit, the site counts page views with GoatCounter, an open-source visit counter run by Martin Tournoij (Ireland) on Hetzner servers in Finland and Germany. It records the page, the site you came from, and your browser, operating system, language, screen width and country. Your IP address is only used to find the country and to avoid counting the same visit twice: it is kept in memory for at most eight hours and never stored. There are no cookies and no profiles. The counts are kept for 1000 days. We count visits to understand how the site is used, which is our legitimate interest (Art. 6(1)(f) GDPR). See GoatCounter’s privacy policy.

Hosting

The site is hosted on GitHub Pages (GitHub, Inc.). Like any web host, GitHub keeps technical server logs, which can include your IP address. See GitHub’s privacy statement.
